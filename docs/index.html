About Me

Hi, my name is Danny Fritz. I'm a passionate software engineer.

I am interested in software development, the web platform, nature, climate change, birds, game engines, graphics, walking, biking, urban planning, reading, and politics.

TypeScript, ReScript, Rust, and Nim are my favorite programming languages to use. But I know and have used many more!

If I could wave a magic wand, all software and data would be liberated and owned and modifiable by its users. The internet would be fun, social, expressive, private, and small again. Software would be made to better humanity instead of to extract money from users.
